🤖X 机器人拉黑助手

隐私政策

最后更新:2026-06-15

「X 机器人拉黑助手」(以下称"本扩展")是一个在 X(Twitter)上用 AI 识别并屏蔽机器人 / 色情 / 引流 / 诈骗账号的浏览器扩展。本政策说明本扩展处理哪些数据、如何使用、以及如何存储。

1. 本扩展处理的数据

为了判断一个账号是否为垃圾账号,本扩展会在你浏览 X 时读取页面上公开可见的账号信息并发送给"判定服务"用于分类:

  • 账号的显示名、用户名(@handle)、简介、头像 URL、关注数等公开资料
  • 账号所发推文 / 回复的文本内容

本扩展不读取、收集或上传:你的私信、密码、浏览历史、其它网站的数据,也不读取你 X 账号的登录凭据。

2. 数据发送到哪里

上述账号信息会发送到你自己选择的"判定服务",二选一:

  • 官方订阅:发送到本项目判定服务端(ai.julineshang.win),用于 AI 实时分类并按"次数"计费;请求携带你的订阅激活码用于鉴权与额度统计。判定内容仅用于实时分类、不作长期留存;仅记录调用次数等用于计费的最小元数据。
  • 自带 API(BYOK):发送到你自己配置的 OpenAI 兼容 AI 端点。数据流向完全由你的服务商决定,本扩展不经手、不留存。

除你选定的判定服务外,本扩展不会把任何数据发送给作者或任何第三方,不出售你的数据,也不用于广告。

3. 本地存储的数据

以下数据仅保存在你浏览器本地(chrome.storage.local),不上传云端:

  • 你的设置(模式、灵敏度、白名单等)
  • 你的 API Key / 订阅激活码(仅本地保存;激活码在调用判定服务时作为鉴权令牌发送)
  • 已拉黑记录、AI 自学习到的高频垃圾词

4. 屏蔽操作

当判定为垃圾账号时,本扩展会复用你当前已登录的 X 会话,调用 X 自身的屏蔽接口完成屏蔽(等同于你手动点"屏蔽")。此操作在你的浏览器内、用你自己的身份完成,不涉及把 X 凭据发送到任何外部服务器。屏蔽可随时在 X 上手动取消。

5. 你的控制权

  • 可随时在弹窗里关闭、切换"只标记 / 自动拉黑"模式
  • 可用白名单永不屏蔽指定账号
  • 卸载扩展即清除所有本地数据

Privacy Policy

Last updated: 2026-06-15

X Bot Blocker uses AI to detect and block bot / spam / escort / scam accounts on X (Twitter).

Data processed

To classify an account, the extension reads publicly visible account info on pages you view (display name, @handle, bio, avatar URL, follower counts) and the text of posts/replies, and sends them to a classification service for analysis. It does not read your DMs, passwords, browsing history, other sites, or your X login credentials.

Where data is sent

Account info is sent only to the classification service you choose: (a) the official subscription backend (ai.julineshang.win), which classifies in real time and logs only minimal billing metadata (call counts), with your subscription key sent as an auth token; or (b) your own OpenAI-compatible endpoint (BYOK), where data flow is governed by your provider. We do not sell your data, use it for ads, or send it to any other third party.

Local storage

Settings, your API key / subscription key, the block log, and learned spam keywords are stored only in your browser (chrome.storage.local) and never uploaded — except the subscription key, sent to the classification service for authentication.

Blocking

Blocking reuses your already-logged-in X session to call X's own block API (equivalent to clicking "Block" yourself). Your X credentials are never sent to any external server. Blocks can be undone on X anytime.
