<p>「X 机器人拉黑助手」(以下称"本扩展")是一个在 X(Twitter)上识别并屏蔽机器人 / 色情 / 引流 / 诈骗账号的<strong>免费</strong>浏览器扩展。本扩展<strong>没有任何作者运营的服务器</strong>:识别在你的浏览器本地完成,可选接入你自己的 AI 服务(BYOK)。本政策说明本扩展处理哪些数据、如何使用、以及如何存储。</p>

<h2>1. 本扩展处理的数据</h2>

<p>为了判断一个账号是否为垃圾账号,本扩展会在你浏览 X 时读取页面上<strong>公开可见</strong>的账号信息,在本地用规则判断;若你配置了自带 AI,还会把这些信息发送给你的 AI 服务用于分类:</p>

<ul>
  <li>账号的显示名、用户名(@handle)、简介、头像 URL、关注数等公开资料</li>
  <li>账号所发推文 / 回复的<strong>文本内容</strong></li>
</ul>

<p>本扩展<strong>不</strong>读取、收集或上传:你的私信、密码、浏览历史、其它网站的数据,也不读取你 X 账号的登录凭据。</p>

<h2>2. 数据发送到哪里</h2>

<ul>
  <li><strong>未配置 AI(默认)</strong>:所有判断在你的浏览器本地完成,账号信息<strong>不会发送到任何地方</strong>。</li>
  <li><strong>自带 API(BYOK,可选)</strong>:账号信息从你的浏览器直接发送到<strong>你自己配置</strong>的 OpenAI 兼容 AI 端点,并携带你的 API Key 用于鉴权。数据流向完全由你选择的服务商决定,本扩展作者不经手、不留存。</li>
</ul>

<p>本扩展<strong>不会</strong>把任何数据发送给作者或任何第三方,<strong>不出售</strong>你的数据,也<strong>不用于广告</strong>。本扩展不含付费功能,不收集支付信息。</p>

<h2>3. 本地存储的数据</h2>

<p>以下数据仅保存在你浏览器本地(<code>chrome.storage.local</code>),不上传云端:</p>

<ul>
  <li>你的设置(模式、灵敏度、白名单等)</li>
  <li>你的 <strong>API Key</strong>(仅本地保存;只在调用你自己配置的 AI 端点时作为鉴权令牌发送给该端点)</li>
  <li>已拉黑记录、AI 自学习到的高频垃圾词</li>
</ul>

<h2>4. 屏蔽操作</h2>

<p>当判定为垃圾账号时,本扩展会复用你<strong>当前已登录的 X 会话</strong>,调用 X 自身的屏蔽接口完成屏蔽(等同于你手动点"屏蔽")。此操作在你的浏览器内、用你自己的身份完成,不涉及把 X 凭据发送到任何外部服务器。屏蔽可随时在 X 上手动取消。</p>

<h2>5. 你的控制权</h2>

<ul>
  <li>可随时在弹窗里关闭、切换"只标记 / 自动拉黑"模式</li>
  <li>可用白名单永不屏蔽指定账号</li>
  <li>卸载扩展即清除所有本地数据</li>
</ul>
