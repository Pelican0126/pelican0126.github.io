这个站原来是一页产品作品集，放在我自己的服务器上；几个产品的介绍页和条款页散在另一个地方，网址也没什么规律。现在全部收拢到了 pelican0126.github.io 下面。

## 网址怎么分

- `/` 首页，先说我是谁。
- `/work/` 全部作品的列表；`/notes/` 笔记；`/about/` 关于我。
- `/<产品>/` 每个产品只有这一个主页，比如 `/panetrans/`、`/fernbudget/`、`/moti/`。
- `/<产品>/privacy/`、`/<产品>/support/` 这个产品的隐私政策和技术支持，直接挂在它下面。
- 英文版在 `/en/` 下面，结构一样。

旧网址都还能打开，会自动跳到新位置。比如原来的 `/spendlytics/privacy.html`，现在会跳到 FernBudget 的隐私政策。

## 还有什么变化

- 多了「笔记」，就是你现在看的这一页，可以用 RSS 订阅。
- 作品从卡片墙改成了一张列表。
- 源码公开在 GitHub 上，页脚有链接。

## 怎么做的

站是用 Astro 写的，构建出来是纯静态页面，托管在 GitHub Pages。标题用的字体是霞鹜文楷，字体文件跟着站点一起托管。

中英文两套页面一一对应，右上角随时切换；如果你的浏览器语言和当前页面不一样，顶部会提示一句另一种语言的版本。

这个站的页面上只有两段小脚本：记住你选的深浅色，和记住你选的语言。没有统计，没有追踪，也不向第三方请求任何东西。
