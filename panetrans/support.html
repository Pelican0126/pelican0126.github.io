Quick start

  1. Install PaneTrans from the Chrome Web Store.
  2. Open any web page with text you want translated.
  3. Right-click → Translate Region, or click the PaneTrans toolbar icon → Drag a region.
  4. Drag a rectangle around the text. A draggable popup appears with the original and translation side-by-side.
  5. The popup keeps re-translating as the underlying text changes — close it with the × when you're done.

Common issues

The first translation is slow.

The first time you pick a translation model, PaneTrans downloads it from Hugging Face's CDN (around 160 MB for OPUS-MT, larger for NLLB / M2M / Gemma). The model is then cached in your browser, so subsequent translations are instant. You can pre-download models from the toolbar popup → Models.

The popup shows the original text but no translation.

Usually means the selected model is still downloading or your machine doesn't have WebGPU. Open the toolbar popup → Models and check the download progress. If WebGPU is unavailable, PaneTrans falls back to WASM (slower but works on any machine).

"Translate Region" isn't in the right-click menu.

Make sure the extension is enabled at chrome://extensions. If you just installed it, reload the page once — the context-menu item is registered when the page loads.

YouTube bilingual subtitles aren't appearing.

Open the toolbar popup, switch the YouTube subtitles toggle on, and reload the YouTube tab. The feature only activates on youtube.com/watch?v=… pages.

OCR (text in images / videos) isn't working.

PaneTrans uses Tesseract.js for OCR; it downloads language data from tessdata.projectnaptha.com on first use. If your network blocks that host, OCR will fail. The error message in the popup tells you which language data is missing.

License keys (Pro)

I bought Pro but my license key didn't arrive.

Check your spam folder for the receipt from Paddle. If it's not there, email us with the address you used at checkout and we'll resend the key.

Activating the key.

Open the toolbar popup → Upgrade → paste the key → Activate. The Pro models (gpt-oss, Gemma 3) become available in the model picker once activation succeeds.

Using Pro on multiple browsers.

Your key activates on multiple browsers — sign in with the same Chrome / Edge / Brave profile and activate again on each one. If you hit the activation limit, email us and we'll reset it.
